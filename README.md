# 🧠 IntelliQuest — Advanced Developer & Engineering Assessment Platform

IntelliQuest is a modern, client-side technical assessment platform designed to evaluate software engineering depth across core computer science and development domains. It presents scenario-driven diagnostic challenges, provides immediate architectural explanations, calculates dynamic competency scorecards, and delivers an interactive feedback experience for learners.

The project is intentionally lightweight and zero-dependency: built with pure semantic **HTML5**, modern **CSS3**, and vanilla **JavaScript (ES6+)** without external frameworks, build tools, backend servers, or databases.

---

## 🎯 Project Goals

- **Comprehensive Assessment Tracks**: Evaluate multi-domain engineering proficiency across 6 specialized areas.
- **Scenario-Based Evaluation**: Benchmark runtime internals, execution orders, and system tradeoffs rather than surface syntax.
- **Instant Architectural Feedback**: Provide detailed technical rationales immediately upon answer verification.
- **Competency Scorecard & Attestation**: Generate dynamic scoring metrics, performance grading, and timestamped certificates.
- **Persistent Dual Themes**: Seamlessly switch between Light and Dark modes with `localStorage` persistence.
- **Client-Side Autonomy**: Maintain a complete evaluation and feedback lifecycle directly in the browser with zero server latency.
- **Fully Responsive Architecture**: Provide a clean, adaptive layout across mobile, tablet, laptop, and desktop viewports.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic page structure, accessible forms, custom modal views, and ARIA live regions.
- **CSS3**: Custom property design tokens, CSS Grid & Flexbox, fluid typography, transitions, and outlined button states.
- **JavaScript (ES6+)**: In-memory state machine, dynamic DOM rendering, event delegation, answer validation, scoring algorithms, and validation engines.
- **Google Fonts**: *Plus Jakarta Sans* for UI typography and *JetBrains Mono* for code-like diagnostic displays.
- **Font Awesome 6**: Vector icons for navigation, track cards, evaluation states, rating stars, and actions.
- **Browser Local Storage**: Persists active theme preferences across browser reloads.
